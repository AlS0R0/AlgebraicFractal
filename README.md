# Algebraic Fractal

Визуализация множества Мандельброта на C++ / Qt Widgets. Приложение
позволяет приближать любую область фрактала, сохраняя пропорции
изображения, и сбрасывать вид правой кнопкой мыши.

## Возможности

- Отрисовка множества Мандельброта в окне Qt
- Выделение произвольной прямоугольной области мышью и зум в неё
- Сохранение пропорций изображения при любом зуме
- Автоматическое увеличение лимита итераций при углублении зума
- Сброс вида к исходному состоянию правой кнопкой мыши
- Кэширование изображения: пересчёт только при изменении вида или размера окна

## Требования

- C++17
- CMake ≥ 3.16
- Qt 5 (≥ 5.15) или Qt 6 с модулем `Widgets`
- Компилятор с поддержкой C++17 (GCC, Clang, MSVC)
